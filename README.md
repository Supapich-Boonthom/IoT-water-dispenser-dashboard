# IoT Water Dispenser Dashboard

หน้าเว็บระบบตรวจสอบและแจ้งเตือนปริมาณน้ำของเครื่องกดน้ำดื่มภายในห้องสมุด มหาวิทยาลัยราชภัฏศรีสะเกษ โดยประยุกต์ใช้เทคโนโลยี Internet of Things (IoT) เพื่อช่วยให้เจ้าหน้าที่สามารถติดตามระดับน้ำและตรวจสอบข้อมูลได้สะดวกยิ่งขึ้น

## ทดลองใช้งานระบบ

[เปิดหน้า Dashboard](https://supapich-boonthom.github.io/IoT-water-dispenser-dashboard/)

## เกี่ยวกับโครงงาน

โครงงานนี้พัฒนาระบบสำหรับตรวจสอบระดับน้ำคงเหลือในเครื่องกดน้ำดื่ม โดยใช้ ESP32 ร่วมกับเซนเซอร์วัดน้ำหนักเพื่อคำนวณปริมาณน้ำที่เหลืออยู่ จากนั้นส่งข้อมูลผ่าน Google Apps Script ไปจัดเก็บใน Google Sheets และนำมาแสดงผลผ่านเว็บ Dashboard

## ความสามารถของระบบ

- **หน้าภาพรวม:** แสดงระดับน้ำล่าสุดและข้อมูลของอุปกรณ์
- **ประวัติระดับน้ำ:** แสดงข้อมูลย้อนหลังในรูปแบบรายการและกราฟ
- **การตั้งค่า:** สามารถกำหนดเกณฑ์ระดับน้ำสำหรับการแจ้งเตือนได้
- **ข้อมูลเจ้าหน้าที่:** แสดงข้อมูลเจ้าหน้าที่ผู้รับผิดชอบ
- **รองรับหลายอุปกรณ์:** ออกแบบให้สามารถต่อยอดรองรับอุปกรณ์เพิ่มเติมได้
- **รองรับการใช้งานบนมือถือ:** ปรับรูปแบบหน้าเว็บให้เหมาะกับหน้าจอขนาดต่าง ๆ

## เทคโนโลยีที่ใช้

- ESP32
- HX711 Load Cell Amplifier
- Google Apps Script
- Google Sheets
- HTML
- CSS
- JavaScript
- Chart.js
- GitHub Pages

## โครงสร้างการทำงานของระบบ

ESP32 + เซนเซอร์วัดน้ำหนัก → Google Apps Script → Google Sheets → Web Dashboard

## วิธีทดลองใช้งานบนเครื่องคอมพิวเตอร์

1. ดาวน์โหลดหรือ Clone Repository นี้
2. เปิดโฟลเดอร์โปรเจกต์ด้วย Visual Studio Code
3. เปิดไฟล์ `index.html` ผ่านส่วนขยาย Live Server
4. ระบบจะแสดงหน้า Dashboard บนเว็บเบราว์เซอร์
